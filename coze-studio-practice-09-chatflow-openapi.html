Chatflow 与 Chat SDK 嵌入

对话流编排 + 嵌入自有站点（概览） · 开源可用 上级目录：Coze 实战总目录

图：探索与开放能力入口

步

操作步骤

1

创建对话流

资源库或应用 IDE → 新建「对话流」(Chatflow)，编辑器仍是工作流画布。

2

编排问答

用开始/结束、LLM、意图识别等节点搭多轮对话。

3

发布到 Chat SDK

应用发布页选择 Chat SDK，按引导拿到 bot_id / token。

4

嵌入页面

使用官方 Chat SDK（@coze-studio open-platform 包）在自有 HTML 挂载对话窗；开源需带 user_id 等适配字段。

Chatflow 适合「人对话」；普通 Workflow 适合「批处理/定时任务（外部 cron）」。
