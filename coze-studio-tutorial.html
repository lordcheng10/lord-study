Coze Studio 源码学习

80 天 · 每天约 30 分钟 · 读懂字节开源的「一站式 AI Agent 开发平台」。 后端 Go（Hertz + Eino + DDD）· 前端 React/TS（Rush 海量包）· 核心在 AgentRun → agentflow → ReAct 与 Workflow Canvas→Compose→Execute。 真路径走读 + 大白话类比 + CSS/SVG 动图，AI 小白也能跟上。

00

开篇 · 这是个什么平台

Coze Studio（扣子工作室开源版）是一站式 AI Agent 可视化开发平台： 搭智能体、拖工作流、挂知识库与插件、调模型，还能用 OpenAPI / Chat SDK 集成到你的产品。

🎯 一句话：Coze = 后端 backend/（Go/DDD）+ 前端 frontend/（Rush+React）+ 合同 idl/（Thrift）。 用户发一句话，主线是 Handler → Application → AgentRun(Pipe) → agentflow(BuildAgent) → Eino ReAct/LLM → 流式回写； 复杂业务则走 Workflow 画布 → Schema → Compose → 节点执行。

🤖

智能体

人设 + 模型 + 插件 + 知识 + 工作流，ReAct 可自主调工具。

🕸️

工作流引擎

几十种节点，Canvas 可视化，底层 Eino compose。

📚

知识库 RAG

切片、Embedding、ES + Milvus 检索。

🔌

插件与模型

OpenAPI 插件 + ModelBuilder 多供应商。

仓库在哪读：业务大脑几乎全在 backend/domain/； 启动看 backend/main.go 与 application/application.go； 跨域协作看 backend/crossdomain/；前端从 frontend/apps/coze-studio 与 packages/agent-ide、packages/workflow 入手。

怎么用这份教程

⏱️

每天 30 分钟

一页一天：类比 → 动图 → 源码坐标 → 动手命令 → 明日预告。

零基础友好

不假设你会 Go/DDD/Eino；术语第一次出现都有大白话。

📍

真仓库路径

焦点文件来自真实 coze-studio 树，可对照本地 clone。

🎨

取舍与坑

每天讲「为什么这样设计」和「一改就炸」的边界。

建议节奏：第 1–2 周建立地图与启动（S1–S2）；第 3–4 周打通对话主线（S3）； 第 5–7 周沉浸工作流深水（S4）；随后补齐 RAG/插件/前端（S5–S7）；最后收官做作品（S8）。
