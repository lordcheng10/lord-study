Day 01 / 共 68 天 · 阶段 0 启程

这行到底在招什么人

这是第一天，还没到写代码的时候。今天我们先弄清楚"目的地长什么样"——AI/Agent 岗位到底招哪几类人、要哪些能力、你该主攻哪条路；这样后面 67 天的每一步都踩在点子上，为明天(Day 02)搭好学习方法和开发环境打基础。

📍 你在 68 天里的位置（阶段 0 · 启程）
D01 招什么人→ D02 学习法&环境→ D03 Python①→ …→ D68 拿 offer
💡 用一个类比兜住今天（今天全程沿用「一支球队」的世界观） 找工作 = 加入一支球队。球队里有前锋、中场、后卫、门将、教练——位置不同、要练的技术就不同；招聘广告(JD)就是球队贴出来的"选人告示"，写清楚这个位置要会哪几招；而这条 68 天路线，就是一份针对性训练计划。今天做的事只有一件：看懂告示、认清位置，再决定自己先练哪个位置——别一上来就闷头狂练，结果练错了方向。
L01

先别急着学代码

🤔 痛点很多人转行第一天就冲去看"Python 21 天速成""LangChain 教程",学了两周发现学的东西招聘根本不太要,越学越慌。问题不在不努力,而在不知道终点长什么样,方向全靠猜。
💡 本质（一句话）先看"选人告示",再定"训练计划"——先搞清岗位要什么,再决定学什么,顺序反了会白费力气。

就像想进球队,你得先知道自己想踢哪个位置:前锋要练射门,门将要练扑救,练反了再努力也上不了场。这行也一样——AI 岗位不是铁板一块,细分下来差别很大。今天先把"地图"摊开,你会发现:转行门槛没你想的那么高,但方向选错了会绕远路。

👶 给零基础的定心丸你现在完全不懂编程、不懂大模型,都没关系。这 68 天就是从"变量是什么"讲到"做出作品拿 offer"。今天你唯一要做的,是看懂大局、选好方向——一行代码都不用写。
L02

5 种岗位原型：球队里的 5 个位置

🤔 痛点招聘网站上标题五花八门:"AI 应用工程师""大模型算法""Prompt 工程师""AI 产品经理"……看着像 100 种岗位,不知道哪个适合自己。
💡 本质标题再多,拆开看其实就 5 种"位置原型",像球队的前锋/中场/后卫/门将/教练——每种要练的核心技能不一样。
位置原型干什么（大白话）核心要练转行友好度
① Agent 应用工程师
前锋·最缺人		用大模型 + 工具搭出能干活的应用:客服机器人、文档问答、自动化助手Python、调 API、RAG、Agent 框架、评测⭐⭐⭐⭐⭐
② 大模型算法工程师
中场·门槛高		训练/微调模型、改模型结构、做前沿研究深度学习数学、PyTorch、论文功底⭐⭐（要科班背景）
③ AI 平台/基础设施
后卫·稳		做支撑上层的底座:推理服务、GPU 调度、网关、监控后端、Docker/K8s、高并发、运维⭐⭐⭐⭐（后端转最顺）
④ AI 数据/评测工程师
门将·把关		造数据、清洗、给模型/Agent 打分做质量把关数据处理、评测指标、LLM-as-Judge⭐⭐⭐⭐
⑤ AI 产品/解决方案
教练·懂全局		定需求、画方案、连接业务和技术懂技术边界 + 业务 + 沟通⭐⭐⭐⭐（有行业经验加分）
📝 举个例子：同一个招聘,翻译成人话 JD 写"负责基于 LLM 构建 Agent 应用,熟悉 RAG 与 function calling,有 prompt 调优经验"→ 翻译:这是招"前锋"(①Agent 应用工程师),要你会调大模型、会给它外挂知识库、会让它调用工具。这正是本路线主攻的方向。
L03

能力地图：一张图看全要练什么

🤔 痛点就算锁定了"前锋"位置,要练的技能还是一长串——Python、大模型、RAG、Agent、评测、部署……到底怎么排先后?
💡 本质把能力想成金字塔:底层是"地基"(编程、调 API),中层是"核心武器"(大模型/提示词/RAG/Agent),顶层是"职业化"(评测/可观测/部署/作品集)。从下往上盖,越往上越值钱、越难造假。

图注：这也正是 68 天路线的阶段顺序——先地基,再武器,最后职业化。

好消息是:金字塔底部两层门槛并不高,零基础按部就班几周就能站上去;而顶层的"评测/可信"恰恰是面试官最看重、最难靠背题糊弄的——这也是转行者能真正拉开差距的地方。

L04

你该主攻哪条路：①②③优先级

🤔 痛点时间有限,不可能 5 个位置都练。零基础/跨行转过来的人,先攻哪个成功率最高?
💡 本质本路线明确押注 ①Agent 应用工程师 为主攻——它最缺人、门槛对转行者最友好、技能可迁移性最强。就像新人进球队,先当"前锋"最容易上场得分。

给你一个清晰的三档优先级:

🥇 主攻①（本路线核心）· Agent 应用工程师不用高深数学,靠"会拼装 + 懂工程 + 会评测"取胜。市场缺口最大,68 天路线就是为它设计的。零基础默认走这条。
🥈 备选③ · AI 平台/基础设施如果你已经是后端/运维工程师,顺手切这条最快——你的 Docker/K8s/高并发经验直接能用。
🥉 加分⑤ · AI 产品/解决方案如果你有某个行业的深厚经验(医疗/法律/金融/客服),懂技术边界后做解决方案,是你独有的护城河。

至于 ②大模型算法,通常要求硕博 + 深度学习功底,不建议零基础转行首选——不是不能,是投入产出比对新人不划算。别被"算法"两个字迷住,应用工程师同样是硬核技术岗、同样高薪。

👶 小白：不搞算法、不训练模型,那还算"真的懂 AI"吗?会不会被看不起?

👨‍🏫 老师：完全不会。打个比方——会造发动机的人很牛,但市场上更缺"会用发动机造出好车、还能保证车不趴窝"的人。绝大多数公司不训练大模型,他们买现成模型(GPT/Claude/国产)来解决业务问题,要的正是①这种"把模型用好、用稳"的工程师。会用、用对、用出效果,本身就是极稀缺的硬本事。

L05

怎么读一份招聘 JD（看告示的方法）

🤔 痛点JD 上一堆名词唬人:"熟悉 RAG/Agent/向量数据库/LangGraph/可观测……",看得人自我怀疑"我是不是不配投"。
💡 本质JD 是"愿望清单"不是"及格线"。学会把它拆成三堆:必会(硬门槛)、加分(会更好)、噪声(HR 堆的名词)。看告示要抓重点,别被吓退。
图注：满足 60%~70% 就大胆投——JD 是理想型,不是打分表。
📝 举个例子：拆解一句真实 JD 原句:「负责 LLM 应用开发,熟悉 RAG、function calling、prompt engineering,了解 LangChain/LangGraph 等框架,有评测和可观测经验者优先」
🔴 必会 = LLM 应用 / RAG / function calling / prompt(前 4 项本路线阶段 2-6 全覆盖);
🟡 加分 = LangChain/LangGraph(阶段 7 深潜)、评测(阶段 9)、可观测(阶段 10);
⚪ 噪声 = "等框架"三个字——不是要你全会,会一个能讲透就够。结论:这份 JD 本路线学完 100% 覆盖。

L06

新手最常踩的 4 个坑

🤔 痛点方向对了,但很多人还是转行失败——不是能力不够,是掉进了几个"努力却无效"的坑。
💡 本质转行不是比谁学的名词多,而是比谁能拿出跑得起来的作品 + 讲得清取舍。就像球员不是背战术手册厉害,而是真上场能踢。
  • 坑① 收藏式学习:囤了 100 个教程、0 个跑通。➡️ 对策:每天动手 10 分钟,哪怕只跑一段代码。
  • 坑② 追新框架:天天换新框架,基础没扎稳。➡️ 对策:先把 Python + 调 API + RAG + 一个框架吃透,胜过样样稀松。
  • 坑③ 只学不做作品:面试拿不出东西。➡️ 对策:路线最后的 3 个作品集就是为此设计,越早开始攒越好。
  • 坑④ 忽视评测:只会"让它跑起来",不会"证明它好用"。➡️ 对策:评测(阶段 9)是面试杀手锏,别跳过。
一句话心态:把这 68 天当"每天进球队训练 30 分钟"。不求猛,求不断、动手、留痕迹(代码提交到 GitHub)。连续两个月后,你的简历会自己说话。
L07

今日小结 + 动手 10 分钟

🧠 今天你应该能回答

  • AI 岗位拆开看主要是哪 5 种"位置原型"?各要练什么?
  • 零基础转行,本路线主攻哪个位置?为什么是它(而不是算法)?
  • 能力金字塔从下到上是哪几层?为什么从底层盖起?
  • 看到一份唬人的 JD,怎么把它拆成"必会/加分/噪声"三堆?

✋ 动手 10 分钟：给自己做一次"定位"

不用写代码,做两件事:

  1. 点开 岗位需求分析页 扫一遍,记下出现频率最高的 3 个技能词。
  2. 去招聘网站搜"AI 应用工程师 / LLM 应用开发",随手复制一份 JD,亲手把每条要求标上 🔴必会 / 🟡加分 / ⚪噪声。

想把这次定位存下来?可以用最简单的方式记一笔(明天装好 Python 就能跑,今天先感受下代码长啥样):

# 在电脑上新建一个笔记文件,记录你的转行定位（终端里执行）
# 井号开头的是注释，给人看的，机器会忽略
echo "主攻方向: Agent 应用工程师(①)" > 我的转行定位.txt   # > 表示写入文件
echo "高频技能TOP3: Python / RAG / Prompt" >> 我的转行定位.txt  # >> 表示追加一行
cat 我的转行定位.txt          # cat = 把文件内容打印出来看看

看不懂这几行没关系——这正是 Day 06 命令行要教的。今天记住"方向定了、动手留痕"这个感觉就够。
