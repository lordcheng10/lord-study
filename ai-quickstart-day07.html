目标：三合一小助手

我们要拼的这个小助手，同时会三样本事——每一样你都已经单独做过了，今天只是把它们装进同一个循环：

本事来自体现在哪
🗣️ 连续聊天、记得住Day 4一个 messages 列表当记忆
🛠️ 遇到算数会算Day 5看到 CALC: 暗号就调计算器
📚 能照你的资料回答Day 6开头把资料塞进 system
🧩 像搭乐高 你前几天做的每个小程序，都是一块乐高积木。今天不学新东西，只是把三块拼在一起——你会发现它们严丝合缝。这正是真实开发的样子：大系统 = 一堆小积木拼起来。
②

动手：~30 行拼出来

新建 assistant.py，把下面这段抄进去。看着行数不少，其实每一块你都眼熟——我在注释里标了它来自哪一天。

from openai import OpenAI
client = OpenAI(api_key="你的钥匙", base_url="https://api.deepseek.com")

# Day6：把你的私有资料塞进 system；Day5：约定算数只回 CALC:表达式
data = "小绿茶饮：支持7天无理由退货；营业时间9:00-22:00。"
rule = f"你是小绿茶饮的客服。只根据资料回答：{data}。遇到算术只回 CALC:表达式。"

messages = [{"role": "system", "content": rule}]   # Day4：这个列表就是记忆

while True:
    q = input("你：")
    if q == "退出":
        break
    messages.append({"role": "user", "content": q})            # Day4：记下你的话
    reply = client.chat.completions.create(model="deepseek-chat", messages=messages).choices[0].message.content

    if reply.startswith("CALC:"):                              # Day5：它想用计算器
        result = eval(reply[5:].strip())                       # 程序动手算
        messages.append({"role": "assistant", "content": reply})
        messages.append({"role": "user", "content": f"计算结果是 {result}，用一句话回答"})  # 回填
        reply = client.chat.completions.create(model="deepseek-chat", messages=messages).choices[0].message.content

    print("助手：" + reply)
    messages.append({"role": "assistant", "content": reply})   # Day4：记下 AI 的话
💡 看懂它的关键整个程序就是一个 while 大循环（连续聊天）+ 一个 if CALC: 小判断（用工具），而资料早在开头就塞进 system 了（读资料）。三块积木，各就各位。

跑起来，试三种本事

运行它：

python assistant.py

按顺序输入这几句，一次性验证三种本事都在线：

试"读资料"：你打 你们几点关门？ → 助手答 22:00（照资料）✅
试"用工具"：你打 买 128 杯，每杯 17 元，一共多少钱？ → 助手先出 CALC:128*17，算出 2176 元 ✅
试"记忆"：接着打 那再打 8 折呢？ → 它记得上一句的 2176，继续算 ✅
