L01

每天 30 分钟怎么分配

🤔 痛点下班后只挤得出半小时,一会儿看视频、一会儿抄代码,学完啥也没记住,还怀疑自己"是不是太笨"。问题不是笨,是没有节奏。
💡 本质把 30 分钟切成固定三段:读 20 分钟(看菜谱)→ 动手 10 分钟(下厨)→ 顺手留痕(拍张成品照发朋友圈=提交 GitHub)。学做饭光看菜谱不动锅铲,永远学不会。
图注：读得再多不如亲手跑一次。哪怕只改一个数字、看输出怎么变,都算"下过厨"。
三条铁律:① 每天必动手,哪怕 5 行;② 报错不慌,复制报错去搜是常态(专业程序员每天都在搜);③ 连续 > 猛冲——每天 30 分钟坚持两个月,远胜周末狂补 5 小时然后弃坑。
L02

要装的"三大件"是什么

🤔 痛点网上教程一上来就是"配置环境变量""解释器""IDE""包管理器"——一堆黑话,还没开始就想放弃。
💡 本质剥掉黑话,今天只装三样东西,对应厨房里的三件设备:
要装的黑话叫说人话就是
Python 3.11+解释器 interpreter灶台。你写的代码,靠它一行行"读懂并执行"
VS Code编辑器 / IDE操作台 + 菜谱本。写代码、点运行、看结果都在这
pip（装 Python 时自带）包管理器楼下调料超市。别人写好的现成工具,一句命令就装上
👶 关键词先扫盲"包"(package)=别人打包好的一坨现成功能,比如"发网络请求""读 Excel",你直接拿来用,不用自己造。"命令行/终端"=一个只能打字、没有按钮的黑框框,输一行命令按回车,电脑就干一件事。别怕它,它其实比点鼠标更快更准。
L03

装 Python 3.11+（装灶台）

🤔 痛点官网下载页版本一堆,Mac 好像自带一个又不敢用,Windows 装完命令行还找不到——第一步就卡住。
💡 本质只要记住一句:去官网 python.org 下最新的 3.11 或更高版本,Windows 安装时务必勾上 "Add Python to PATH"(把灶台接进你家电路,不然找不到)。

Windows:打开 python.org/downloads → 下载 → 双击安装 → 第一屏一定勾选"Add python.exe to PATH" → Install Now。

macOS:同样去 python.org/downloads 下 macOS 版安装包(系统自带的那个太旧,别用),双击装好。

装完,打开终端(Windows 叫"命令提示符/PowerShell",Mac 叫"终端 Terminal"),输一行验货:

# 查看已安装的 Python 版本，验证装成功了没
python --version
# 期望看到类似：Python 3.11.9 （3.11 或更高就对了）
# 如果 Mac 上提示找不到，试试 python3 --version
📝 举个例子：一行命令三种结果,怎么判断 输入 python --version 后:
✅ 显示 Python 3.11.9 → 灶台装好了,进下一步;
⚠️ 显示 Python 2.7.x → 太旧了(Mac 常见),改用 python3 --version 看;
❌ 显示 不是内部或外部命令 / command not found → PATH 没配好,Windows 重新装并勾 "Add to PATH",或重启终端再试。
L04

装 VS Code（搭操作台）

🤔 痛点用记事本写代码?没有颜色、没有提示、报错找不到行——像在黑暗里切菜。
💡 本质装 VS Code(免费、最主流)当操作台:代码会自动上色、打错会划红线、点一下就能运行。它就是你接下来两个月天天待的"厨房台面"。
  1. 打开 code.visualstudio.com,下载对应系统版本,安装。
  2. 打开 VS Code,左侧点"扩展"(四个方块的图标),搜 Python(微软官方那个),点 Install。这个扩展让 VS Code 认识 Python、能一键运行。
  3. 再搜装 Chinese (Simplified) 语言包(可选),界面变中文更友好。
👶 别纠结工具选择你可能听过 PyCharm、Cursor、Jupyter 等等。零基础先用 VS Code 就好,免费、资料最多、后面接 AI 编程也顺。工具是锅,先学会做菜,以后想换锅随时换。
L05

Hello World（点第一把火）

🤔 痛点装了半天工具,还没写过一行"自己的代码",没有成就感,不确定环境到底通没通。
💡 本质写一个只有一行的程序,让屏幕打印一句话。能打印出来,就说明"灶台+操作台"全线打通——这是每个程序员的开门仪式。

步骤:VS Code 里 → 文件 → 新建文件 → 保存为 hello.py(.py 是 Python 文件的后缀)→ 写下这一行 → 右上角点"运行"三角 ▶️:

# hello.py —— 我的第一个程序
# print 是"打印"的意思，把括号里的内容显示到屏幕上
# 引号里的文字叫"字符串"，就是一段普通文本
print("Hello World, 我要转行做 Agent 工程师！")

屏幕下方的"终端"窗口应该冒出这句话。恭喜——你人生第一个程序跑起来了 🎉。

图注：以后所有程序,本质都是这个"写→执行→看结果"的循环,只是内容越来越复杂。

👶 小白：我点运行报了一堆红字,是不是把电脑搞坏了?好慌!

👨‍🏫 老师：放一百个心,写代码报错啥都不会弄坏,顶多程序不跑而已。红字叫"报错信息",它其实在帮你——最后一行通常写着错在哪、第几行。最常见就俩:引号用了中文引号"",或括号没配对。把红字最后一行复制去搜索引擎/问 AI,90% 一搜就解决。报错是家常便饭,不是失败。

L06

pip：从"调料超市"装现成工具

🤔 痛点以后要"发网络请求调大模型""读 PDF"……这些难道都要自己从零写?那得写到猴年马月。
💡 本质不用!全世界程序员早把常用功能打包成"包"放在网上了。pip 就是帮你下单的快递员——一句 pip install 包名,现成工具直接到货。这就是楼下的调料超市:缺酱油不用自己酿,下楼买一瓶。

试装一个后面天天要用的包 requests(用来发网络请求,Day 07 会正式用它调 API):

# 用 pip 安装 requests 包（发网络请求的现成工具）
pip install requests
# Mac 上如果 pip 不好使，试试 pip3 install requests

# 装完验证一下：进入 python，导入它不报错就说明装好了
python -c "import requests; print('requests 装好了！版本', requests.__version__)"
📝 举个例子：有 pip 和没 pip 的差别 想让程序"下载一个网页":
❌ 没有现成包 → 你得手写几百行处理网络连接、协议、编码……几天都未必搞定;
✅ 用 pip 装了 requests → 两行搞定:import requests 然后 requests.get("网址")。
"站在别人肩膀上"就是编程的日常,一点都不丢人,反而是本事。
小知识:装包默认从国外服务器下,可能慢。国内可以加个"就近仓库"加速,比如 pip install requests -i https://pypi.tuna.tsinghua.edu.cn/simple(清华镜像)。现在记不住没关系,慢的时候回来抄这行。

✋ 动手 10 分钟：把厨房彻底跑通

今天的动手就是"装好并验货",这本身就是最重要的练习。照着做完这四步:

# 1. 验证 Python 灶台（应显示 3.11+ 版本号）
python --version

# 2. 验证 pip 快递员在线
pip --version

# 3. 装一个后面要用的包
pip install requests
# 4. 新建 day02.py，写下面几行并运行，见证环境全线打通
print("环境准备完成 ✅")
print("我坚持第 2 天了！")
# 顺便预习一个变量：把名字存进一个"盒子"再打印（Day 03 详讲）
name = "未来的 Agent 工程师"   # name 是变量名，= 表示把右边存进左边
print("我是", name)

四步都出结果 = 你的开发环境 100% 就绪。截个图存着,这是转行的第一个里程碑。
