开篇 · 这是个什么项目

我们要读的这个仓库 claude-code-best，是一个逆向实现（reverse-engineered）的 Anthropic Claude Code CLI——也就是"在终端里跟你结对编程的 AI 助手"的一个开源复刻版，而且加了不少官方没有的功能（远程控制、workflow 编排、语音等）。

🎯 一句话：它是一个跑在终端里的 AI Agent——你用自然语言下命令，它自己调用工具（读写文件、跑命令、搜索代码…）把编程任务干完。本教程带你逐层读懂"这样一个 Agent 从按下回车到干完活，内部到底发生了什么"。

它用 TypeScript 写、跑在 Bun 上、界面用 React + Ink 渲染到终端。规模不小：2500+ 个 .ts + 700+ 个 .tsx，还是个 monorepo。别被吓到——我们会顺着"一次对话的旅程"这条主线，把复杂度拆成 20 天可消化的小块。

为什么值得读？ 因为它是当下最热的一类软件——"Agentic CLI"——的完整、真实实现。读懂它，你就理解了 agent 循环、工具调用、权限、MCP、终端 UI 这些 AI 应用的核心工程，能力可迁移到任何 AI 产品开发。
01

Agent 循环总图（动起来看）

整个 CLI 的灵魂就是一个循环。下面这颗发光的小球会绕着圈跑——它就是一次任务在 Agent 内部转的圈：你说话 → 模型思考 → 要用工具 → 执行工具 → 结果喂回模型 → 再思考……直到任务完成。今天不用懂细节，先把这个"圈"刻进脑子。

Agent
Loop周而复始
直到完成
① 用户输入你的需求
② 请求模型拼上下文+工具
③ 流式回复文字/工具调用
④ 执行工具读写/跑命令
⑤ 回填结果喂回下一轮

落到这个项目里，这个圈由 src/QueryEngine.ts / src/query.ts 驱动，工具在 packages/builtin-tools，界面在 src/components（Ink）。这三块 + "什么时候停"的判断，就是核心中的核心（Day 03、06–10 细讲）。
