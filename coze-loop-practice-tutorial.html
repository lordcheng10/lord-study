按开源版真正能点的核心能力拆成 8 课。每课为跟做版：步骤尽量拆细、小白可读； 截图紧跟在对应步骤下方，关键按钮/区域用红框 + 中文标注标出。 与 Loop 源码课互补——那边读引擎，这边点界面闭环。 推荐起点：P00 环境与登录 → P01 Prompt。

00

开篇 · 你要交付什么

一句话 在本地开源 Coze Loop 走通：配模型 → 写 Prompt → 建评测集 / 评估器 → 跑实验 → 看 Trace → 打标签 → 开 PAT。 它不负责拖拽搭 Agent（那是 Coze Studio），而是给 Agent / Prompt 做「调优 + 质检 + 巡检」。
怎么读每一课 从上往下跟做即可：① 读「为什么」→ ② 按编号子步骤点界面 → ③ 看步骤下方带红框的截图对照 → ④ 用「验收」勾选是否成功 → ⑤ 踩坑提示先看一眼再动手。 截图目录：assets/coze-loop-practice/marked/（标注版）；原始图在同级数字目录。
