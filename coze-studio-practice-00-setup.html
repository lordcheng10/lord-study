Coze 实战 · P00 / 共 10 课 · ≈25 min · 开源可用

P00 · 环境启动 · 登录 · 模型配置

本课是后续所有实战的硬前置：服务起来、能登录、至少一个模型为「启用」。上级：实战总目录。

0

前置条件

项要求
机器建议 ≥ 2 核 / 4GB 内存；已装 Docker Desktop
代码已 clone 开源仓库 coze-studio
模型 Key至少一家云厂商 API Key（Claude / OpenAI / 豆包等任选）
浏览器Chrome / Edge 最新版
本课不配好模型，后面智能体调试与工作流 LLM 节点都会失败（Tokens=0 或报错）。
1

启动本地服务

作用：拉起前端 + Go 后端 + MySQL/Redis/ES/MinIO 等中间件，UI 固定在 8888。
cd /path/to/coze-studio
# 首次可先配置 docker/.env（一般直接用仓库示例即可）
make web
# 等待容器就绪后访问：
open http://localhost:8888
✅ 验收：浏览器打开 http://localhost:8888 能看到登录/注册页，而不是连接拒绝。
常见卡点 端口占用：8888 被占时改 docker 映射或关掉冲突进程。
内存不足：Docker Desktop 把资源调到 ≥4GB 后 make clean && make web。
2

注册并登录

作用：开源版用邮箱自建账号；登录后进入 Personal Space。
  1. 打开 http://localhost:8888/sign
  2. 首次点「注册」，填写邮箱 + 密码；之后用同一账号登录
  3. 成功后应跳到 /space/<space_id>/develop（项目开发）

图：登录页。邮箱框 + 密码框 +「登录 / 注册」

图：登录成功后的「项目开发」页。左侧是工作空间导航，右侧是智能体/应用卡片。

✅ 验收：能看到「+ 创建」按钮，以及「项目开发 / 资源库」侧栏。
3

配置并启用模型（必做）

作用：管理后台登记云厂商模型；智能体/工作流下拉才能选到它。
  1. 浏览器打开 http://localhost:8888/admin/#model-management
  2. 左侧确认在「配置管理 → 模型管理」
  3. 在列表里找到你要用的厂商卡片（Claude / 豆包 / OpenAI / Deepseek …）
  4. 点该卡片右侧 添加模型
  5. 按下表填写 → 保存
  6. 列表行里确认状态为绿色 启用（若是禁用，点启用）

图：模型列表。实录已有 claude-v1（ID 100003，模型 claude-sonnet-4-6，状态启用）。

图：点「添加模型」后的表单（各厂商字段类似；示例为豆包表单，Claude/OpenAI 同理）。

可复制字段说明（以 Claude 为例）

表单字段填什么示例
模型显示名称 *你在 UI 里看到的名字claude-v1
Model *厂商真实模型 IDclaude-sonnet-4-6（按你账号可用型号改）
API Key *厂商控制台复制的密钥sk-...
Base URL可选；走代理/兼容网关时填留空或厂商文档地址
Thinking Type新手保持 DisableDisable
密钥不要提交到 git。教程截图里 Key 会打码；你本机保存后列表行只显示部分字符属正常。
常见卡点 保存成功但智能体下拉没有：确认该行是「启用」而不是禁用。
调用 401：API Key 错或 Base URL 与厂商不匹配。
管理后台进不去：确认服务已起，地址是 /admin/#model-management（带 hash）。
