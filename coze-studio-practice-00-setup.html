步

操作步骤

1

启动服务

在 coze-studio 根目录执行 make web，浏览器打开 http://localhost:8888。

2

注册 / 登录

进入 /sign，用邮箱注册或登录，成功后进入 Personal Space。

3

配置模型（必做）

打开 /admin/#model-management，按厂商模板添加模型并填写 API Key / Model ID，状态设为启用。

4

验收

回到项目开发页，新建智能体时模型下拉能看到刚启用的模型。

不配模型：智能体调试与工作流 LLM 节点都会失败。开源支持 OpenAI / Claude / 豆包 / Gemini / Qwen / DeepSeek / Ollama 等模板（见 backend/conf/model/template/）。
