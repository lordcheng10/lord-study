观测 Trace：调用链与筛选

本地 localhost:8082 实录 · 开源可用 上级：Loop 实战总目录

★

界面实录

图：Trace 列表（Prompt 平台有数据）

图：Trace 详情：PromptExecutor → Claude Sonnet，Success，可见输入输出 JSON

图：时间范围与筛选工具条

步

操作步骤

1

打开 Trace

侧栏 → Trace。

2

产生数据

在 Prompt 开发 / Playground 运行调试后会自动产生 Trace（本实录可见 PromptExecutor → Claude Sonnet 成功 span）。也可经 OpenAPI / SDK 上报。默认数据源若选「SDK 上报」可能为空——改成 Prompt 或放宽过滤器。

3

看详情

点开一条 Trace：左侧看调用树与耗时，右侧看 Input/Output JSON、Token、状态。本实录输出含「我是 Claude，由 Anthropic 开发…」。

UI 不提供「上传 Trace 文件」；列表为空时优先检查平台过滤器是否为 Prompt，而非仅 SDK。
