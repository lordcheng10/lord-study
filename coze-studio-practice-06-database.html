P06 · 数据库记忆读写

上级：实战总目录。文件命名规范：coze-studio-practice-NN-slug.html。

0

前置

  • □ 已登录；建议已会建工作流（P01）或智能体（P02）
  • □ 本课用一张「竞品活动」表走通写入 + 查询
和知识库区别：知识库适合非结构化文档检索；数据库适合结构化行（日期、交易所、活动名）供 CRUD。
1

资源库创建数据库

  1. 侧栏打开 资源库
  2. 右上角 + 创建 → 选 数据库
  3. 名称填：competitor_campaigns（建议英文下划线）

图：资源库（创建数据库入口）。

图：创建资源菜单 — 选数据库。

2

定义字段（可照抄）

字段名类型说明
exchangeText交易所，如 Binance
campaignText活动名称
report_dateText / Date日期 YYYY-MM-DD
noteText备注
开源对高级 SQL / 复杂索引有裁剪；先用表单字段 + 工作流 Database 节点即可。
✅ 保存后资源库列表能看到该数据库。
3

工作流里写入再查询

  1. 打开任意应用内工作流，或新建最小工作流：开始 → Database → 结束
  2. 添加 Database 节点：选表 competitor_campaigns，操作「插入」
  3. 字段映射示例：exchange=Binance，campaign=Launchpool 试写，report_date=2026-07-16
  4. 再加一个 Database 节点「查询」，按 report_date 过滤
  5. 试运行，确认查询结果含刚写入的行
踩坑：节点选错表 / 字段未映射试运行报空结果时，先在资源库手工看表数据是否写入。
4

挂到智能体记忆区

  1. 打开 Agent IDE → 记忆 / 数据库相关入口（与知识库并列，文案因版本可能叫「数据库」）
  2. 添加 competitor_campaigns
  3. 人设补充：
当用户询问「某日有哪些竞品活动」时，优先查询已挂载的数据库表 competitor_campaigns，
用表格列出 exchange / campaign / report_date；查不到就明确说没有记录。
5

验收清单

  • □ 资源库存在表 competitor_campaigns 且含 4 个字段
  • □ 工作流试运行能插入并查回至少 1 行
  • □（可选）Agent 对话能引用库内记录作答
