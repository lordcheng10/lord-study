P02 · 评测集：建表 · 列配置 · 添加数据

建一张评测数据表（input / 参考答案），为后面的实验准备弹药。 截图红框为操作重点。上级：总目录。

🎯 本课目标（先读再动手）

  • 理解评测集 = 考试卷：每一行是一道输入题，可带参考答案。
  • 新建一张评测集，看懂默认列 input / reference_output 的含义。
  • 至少添加 1～3 行真实数据，使后续实验有内容可跑。
学完怎样算过关：评测集列表里有你的表；详情页表格至少 1 行数据；你能说清两列各自干什么。
图上的红色编号框标出你要点的位置。每一大步都写了目的（为什么做）和作用（做完得到什么）。请按「目标 → 步骤文字 → 对照截图」顺序做；做完看每步绿色验收。
1

打开评测集列表

目的：进入「考试卷」管理页，找到创建评测集的入口。

作用：评测集是实验（P04）的必选原料。没有评测集，实验向导选不出数据，整条评测链路走不通。

  1. 左侧侧栏找到分组 评测
  2. 点 评测集
  3. 注意按钮文案是 新建评测集（不是「创建」）

图：侧栏点「评测集」，右上角点「新建评测集」。

✅ 验收：面包屑为「评测 / 评测集」。
2

填写名称与描述

目的：给这张评测表起一个人和机器都能认的名字，并可选写清用途。

作用：名称会出现在列表和实验向导的下拉里。起得清楚（如「问候评测集」），后面选数据时不会选错表。

  1. 点 新建评测集 进入表单页
  2. 名称（必填）：例如 问候评测集，最多约 50 字
  3. 描述（可选）：写清楚这张表用来测什么

图：新建页结构——上半基本信息，下半列配置，右下角「创建」。

图：名称是必填项，空着点创建会被拦住。

✅ 验收：名称框有内容，字数计数在限制内。
3

看懂默认列（Schema）

目的：理解评测集的「表头」——每一列代表什么字段、后面实验如何取数。

作用：列名是评估器 / 字段映射的钥匙。默认 input 喂给模型，reference_output 当参考答案；名字乱改会导致映射对不上。

  1. 默认已有两列：
    • input：投递给评测对象（模型）的输入
    • reference_output：期望的理想输出，可作评分参考
  2. 每列可设：数据类型（String 等）、是否必填、描述
  3. 需要更多字段时点 添加列
  4. 新手第一张表：先用默认两列，不要改名

图：红框标出默认两列。先理解再改，避免实验阶段对不上字段。

✅ 验收：你能说清 input 和 reference_output 各干什么。
4

点「创建」进入详情

目的：把表单里的 Schema 真正保存成平台上的一张评测集，并进入可加数据的详情页。

作用：创建前只是草稿表单；创建后才有 ID，才能「添加数据」「新建实验」「提交版本」。地址栏会出现数据集 ID。

  1. 检查名称和列无误
  2. 点页面右下角蓝色 创建
  3. 成功后进入评测集详情：可添加数据、看关联实验、提交版本

图：详情页。右上常见「添加数据」「新建实验」「版本记录」等按钮。

✅ 验收：地址栏变成 .../evaluation/datasets/一串数字。
5

添加至少一行数据

目的：往评测集里写入真实「考题」行，让实验有东西可跑。

作用：空表启动实验等于空跑。至少 1～3 行后，实验才能产出行级结果；也可再「提交新版本」固化数据快照。

  1. 在详情页点 添加数据（或「手动添加」类按钮）
  2. 在弹出的抽屉 / 表单里：
    • input 例：你好，我叫小明
    • reference_output 例：你好小明，很高兴认识你！
  3. 点确认 / 保存
  4. 回到表格，应能看到新行

图：添加数据时的侧栏 / 弹层（界面可能随版本略有差异）。

图：保存后数据出现在列表中。可再点「提交新版本」固化数据集版本。

✅ 验收：表格里至少 1 行；后续建实验时能选到这个评测集。
找不到「添加数据」？ 确认你在详情页而不是列表页；列表页只有「新建评测集」。
