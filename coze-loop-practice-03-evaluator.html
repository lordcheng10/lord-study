步

操作步骤

1

打开评估器

侧栏 → 评估器。默认「自建」页签；切到「预置」可浏览内置模板。

2

LLM 评估器

新建 → LLM：用 Prompt 让模型打分（准确度、相关性等）。调试前需模型配置。

3

Code 评估器

新建 → Code：用 Python/JS（FaaS）写确定性规则，例如字符串相等、正则。

4

版本与调试

进入详情可改草稿、提交版本、对单条样例调试。

实验可以不绑评估器（纯人工标注）；自动化打分再挂 LLM/Code 评估器。
