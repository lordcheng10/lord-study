02

起手 · 三选一

# 在 gov-agents-platform/ 根目录执行
uv run agentctl new agent my-agent --pattern supervisor --specialists "a_sp,b_sp" --critic both

生成后首要检查目录：

  • apps/my-agent/my_agent/builder.py — 图装配
  • apps/my-agent/my_agent/server.py — API
  • apps/my-agent/my_agent/nodes/ — 节点（无 builder.py）

04

server.py · 文件位置

只改：apps/my-agent/my_agent/server.py · 使用 build_v1_router · 不要手写 /agents/.../run。

反模式：在 nodes/ 或别处新建 server · 或改 gov-agents-server 的业务逻辑。

cd gov-agents-platform
uv sync --all-packages
