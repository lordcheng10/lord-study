git clone git@gitlab.bitmartpro.com:exchange/code/architecture/gov-agents-platform.git
cd gov-agents-platform
uv sync --all-packages
export ANTHROPIC_API_KEY=...
uv run agentctl --help
02

起手 · 三选一

推荐 · agentctl new

uv run agentctl new agent release-notes-bot \
  --pattern supervisor \
  --specialists "diff_sp,changelog_sp" \
  --critic both

6 个 pattern：supervisor（默认）· rag · monitor · doc · business-data · minimal

或 agent-creator（AI 生成 · dry-run 先看预览）：

uv run agentctl invoke agent-creator \
  --data '{"description":"做一个 ...","dry_run":true}'

或 cp 最接近的老 agent：

cp -r apps/sre-rca-agent apps/my-agent && mv sre_rca my_agent
包名铁律：顶层 Python 包必须 snake_case 且独特（my_agent ✓ · agent / app ✗）。

04

server.py · build_v1_router

反模式：❌ @router.post("/agents/my-agent/run") 手写 · ❌ 自己拼 envelope · ❌ 手动改 ANTHROPIC_API_KEY env

✅ 用工厂挂 6 个 endpoint（invoke / stream / cases / feedback + legacy alias）：

from ai_trust_toolkit.api import (
    AgentOutcome, CallContext, CostTracker, build_v1_router,
    anthropic_key_override, make_case_store_from_env,
)

async def _invoke(body, ctx: CallContext, tracker: CostTracker) -> AgentOutcome:
    req = MyAgentRequest.model_validate(body)
    with anthropic_key_override(ctx.anthropic_api_key):
        final = await graph.ainvoke(_initial_state(req))
    return AgentOutcome(
        status="success" if final.get("critique_passed", True) else "critic_end",
        result=_final_to_result(final),
        retry_count=int(final.get("retry_count", 0)),
    )

def build_router(case_store=None):
    router = APIRouter(tags=["my-agent"])
    router.include_router(build_v1_router(
        agent_name="my-agent", invoke_fn=_invoke,
        case_store=case_store or make_case_store_from_env(),
    ))
    return router

BOM 依赖：ai-trust-toolkit-bom[core,supervisor]==0.6.0 + workspace source。不要直 pin toolkit 子模块。
