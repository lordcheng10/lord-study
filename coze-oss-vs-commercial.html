Coze 开源版 vs 官方商业版：深度对比报告

本版在初版基础上补齐：三类 Agent、技能体系、文件化长期记忆、云手机/云电脑、视频创作、AI 编程、套餐权益、 开源 Connector 仅 3 个、工作流全部 NodeType、以及 IS_OPEN_SOURCE 裁剪的文件级证据。 资料来自 docs.coze.cn 与本地 coze-studio。

建议阅读路径：00→01→04→11→14→16（约 25–40 分钟精读）；需要落地选型再读 12/13/15。

00

一句话结论（增强）

💡 核心判断 开源 Coze Studio开放的是「扣子开发平台 / 低代码项目」那一代的编排引擎 （SingleAgent + Workflow + Knowledge + Plugin，可自托管）。 官方扣子（2025–2026）已演进为AI 团队协作操作系统：项目、多人、多 Agent 类型、 文件化记忆、云设备、视频项目、AI 编程；并按套餐分层解锁云端 Agent / 本地 Agent 数量 / 去水印等。 二者同源不同产品边界——引擎能盖楼，协作台还带工地、工人、设备与项目管理。

🧩 开源 Studio

私有化引擎。Go DDD + Eino + Rush。渠道只剩 Chat SDK / API / Coze。无音色、无多人协作 adapter、无云设备。

👥 扣子协作台

人+多 Agent 项目制。扣子/云端/本地三类 Agent。记忆落盘 Markdown。云手机/云电脑操作真实世界。

💻 扣子编程

Vibe Coding 到上线：网页/App/小程序/技能；沙箱、DB、一键部署、多人开发排队。

🧬 低代码线

官方称低代码是「扣子编程较早期版本」，与开源能力面最接近。

大白话 开源给你「装修设计软件 + 自建水电」；商业给你「带云电脑的装修公司 + 视频工作室 + 编程外包队」，还按套餐卖工人数量。

03

定位三角对照

开源 Studio

  • 交付物：可部署软件引擎
  • 用户：私有化 / 二次开发 / 学源码
  • 交互：Bot IDE + 工作流画布
  • 运维：自己扛中间件与安全
  • 许可：Apache 2.0

扣子协作台

  • 交付物：SaaS + 桌面/移动
  • 用户：创作者与业务团队
  • 交互：项目 / @Agent / 工作台
  • 运维：平台托管+套餐
  • 许可：服务条款+积分

扣子编程

  • 交付物：云端开发→上线
  • 用户：要出 App/网页的人
  • 交互：自然语言 + 预览
  • 运维：沙箱/部署平台包办
  • 计费：编程任务+内置集成
问题开源协作台编程
数据能否不出网？可以自托管平台侧平台侧
能否改平台内核？改 Go/React不可可改生成项目
今日能否开始干活？需 Docker+配模型注册即用浏览器即用
团队多人一起改同一 Bot/工作流？adapter 空项目协作多人编程
04

Agent 形态：商业三类型 vs 开源 SingleAgent

这是差距最大的一层。官方文档把 Agent 分成三种运行环境；开源只有「平台内 SingleAgent」一种。

框架扣子 Harness扣子 / OpenClaw / Claude Code / Codex CLIOpenClaw / Claude Code / Codex CLIEino ReAct + agentflow
行业模板投资/法务/自媒体/科研…部分模板—template 域弱于 SaaS

日程/邮箱/云手机工作台完整仅部分—无
套餐门槛默认可用高阶及以上才可创建免费限 1 个起无 SaaS 套餐，自运维
源码位置闭源平台闭源 + 托管框架桥接闭源agent_flow_builder.go
能力矩阵（官方 agent_overview）
能力扣子 Agent云端本地开源

怎么对齐理解开源 Agent 开源的 SingleAgent ≈「低代码智能体」：人设 Prompt + 模型 + 插件/工作流/知识/变量，用 Eino ReAct 跑。 它不是商业「扣子 Agent 工作台」，更不是云端 Claude Code。
⚠️ 别期望在开源里 @ 多个专家 Agent 或接本机 Claude Code——那需要商业的项目模型和 coze-bridge，仓里没有。
05

技能 / 插件 / 工作流：三套「外挂能力」别混

概念商业扣子怎么说开源怎么实现差异要点
技能 Skill 把流程/最佳实践打包成可复用「操作说明书」；商店可交易；对话里 / 或加号加载 无同名「技能」产品域 商业是内容化能力单元；开源用 Plugin/Workflow 替代部分场景
插件 Plugin 仍存在于低代码线；官方插件商店 domain/plugin OpenAPI/MCP 调用 开源需自配第三方鉴权 Key
工作流 Workflow 低代码拖拽；编程侧可生成全代码工作流 domain/workflow 节点最完整 开源是最强对标项之一
Prompt 人设+技能指令；可 AI 生成 prompt 域有；AI 生成被 adapter stub 见 adapter/resources/src/prompt
设计变迁 商业把「可复用方法论」从零散 Prompt/工作流上提成「技能」产品，并接商店交易——这是生态与变现层，不会进入 Apache 开源核心。 开源继续用工程味更浓的 Plugin + Workflow。
06

记忆：文件化长期记忆 vs 变量/数据库

商业 · 持久化长期记忆

  • 不是只靠上下文窗口
  • 自动抽偏好/事实 → 写入 MEMORY.md 等 Markdown
  • 定期整理；可用向量检索召回
  • 用户可在文件目录查看、纠正
  • 跨对话、跨场景累积

开源 · memory 域

  • variables：变量元数据与实例
  • database：用户表/行，工作流节点读写
  • 会话 message 落库作短期历史
  • 没有「MEMORY.md 产品化记忆浏览器」
  • 要长期记忆需自研或外部向量库方案
对齐说法 开源「记忆」≈ 结构化变量 + 可选数据库 + 对话历史。 商业「记忆」≈ Agent 工作台级的文件化认知资产。名字相同，产品厚度完全不同。
07

协作与权限：项目制 vs Space 用户

官方协作流：创建项目 → 邀请人类成员 / 添加 Agent → 补背景 → @ 推进 → 沉淀文件与产出。 项目协作不收功能费，但对话计费由 Agent 创建者承担。

操作项目创建者（商业）人类成员（商业）开源
改/删项目✔️➖无对等「项目」产品
邀请人类成员高阶套餐起➖多人协作 adapter 返回 null
添加/移除 Agent✔️可加；仅移自己的单用户 Agent
@ 人类或 Agent✔️✔️无
frontend/packages/workflow/adapter/resources/src/auth/index.tsx
/** The open source version does not currently provide multi-person collaboration capabilities */
export const CollaboratorsBtn = _props => null;
export const getIsCozePro = _props => false;
⚠️ 开源有 Space/User，那是租户隔离，不是商业「项目多人协作」。不要把 Space 误读成项目协作。
08

商业独占产线：云设备 · 视频 · AI 编程

云手机 / 云电脑

为 Agent 配备真实可操作环境：云手机（Android 13，刷 App、回私信）；云电脑（Ubuntu，写代码、浏览器自动化、文件处理）。 免费/进阶不可用积分兑换；高阶起开放，旗舰起可扩容规格。

开源完全没有 没有虚拟机编排、没有设备代理协议。

视频制作（Seedance 2.0）

剧本→分镜→成片→自然语言剪辑；角色音色统一；导出剪映工程 / MP4。

商业：对话生成漫剧/短剧 套餐影响排队通道与去水印 开源：0 相关域

AI 编程（可在扣子内调编程 Agent）

支持类型商业开源
网页 / App / 小程序 / 技能项目有无沙箱 IDE
云端编辑器+终端+隔离沙箱有无
一键部署自定义域名有仅 Docker 自部署 Studio 本身
多人协作开发队列有无
边界 这三块是「平台云资源 + 多模态模型 + 客户端」组合拳，不属于「Agent 编排引擎」开源范围。用引擎对标它们会系统性低估商业价值。
09

发布渠道：商业一键渠道 vs 开源三 Connector

商业扣子 Agent 可一键发到飞书、微信等渠道。开源 AllConnectorInfo 写死只有 3 个：

backend/domain/connector/service/connector_impl.go
connectors := []*entity.Connector{
  { ID: WebSDKConnectorID, Name: "Chat SDK", ... },
  { ID: APIConnectorID,    Name: "API", ... },      // OAuth2 / PAT
  { ID: CozeConnectorID,   Name: "coze", ... },
}
frontend/.../account-adapter/.../utils/index.ts
// The open-source version does not support channel authorization and has not been implemented yet.
export const connector2Redirect: Connector2Redirect = () => undefined;
含义 开源发布面是「嵌到你自己系统」（SDK/API），不是「发到社交超级 App」。要飞书机器人需自接，官方渠道授权重定向是空实现。

IS_OPEN_SOURCE 裁剪清单（文件级证据）

商业不是「多几个配置项」，而是前端用特性开关与 adapter 挖空。完整到注释的例子：

文件证据摘要影响
workflow/adapter/resources/src/voice/index.tsx open source does not provide timbre；open 空、modal:null 音色选择不可用
.../resources/src/auth/index.tsx CollaboratorsBtn=null；getIsCozePro=false 多人协作 UI 消失
.../resources/src/prompt/index.tsx no AI generation capabilities 提示词 AI 生成关
foundation/account-adapter/.../utils/index.ts connector2Redirect=undefined 渠道 OAuth 跳转无
agent-ide/model-manager/.../model-option Paywall, open source does not support 付费墙/模型营销关
agent-publish/.../publish-result publish_management && !IS_OPEN_SOURCE 发布管理能力裁剪
workflow/.../workflow-global-state-entity.ts 协作模式相关判断绑 !IS_OPEN_SOURCE 协作编辑灰发/关闭
workflow/.../trigger-service.ts projectId && !IS_OPEN_SOURCE 项目触发器路径裁剪
README.zh_CN.md 音色等限商业版本 文档书面确认
读开源技巧 把所有 *-adapter 和 IS_OPEN_SOURCE 分支当「差分说明书」扫一遍，比空谈「功能差异」准确 10 倍。
12

架构与部署对比

开源部署

  • make web / make debug
  • 单（或容器）Hertz：API+静态
  • 自管 MySQL/Redis/ES/Milvus/NSQ/MinIO/etcd
  • 模型 Key 自备；admin 配置
  • 公网需自防：注册口、代码沙箱、SSRF、越权

商业云

  • coze.cn / code.coze.cn / 客户端
  • 账号、计费、限流、模型路由统一
  • 云设备与沙箱是一等公民资源
  • 开发/生产隔离、密钥加密环境变量
  • 一键部署、回退、日志
架构税 开源让你付「中间件+安全+渠道自建」税，换数据主权与可改引擎。 商业让你付「积分/套餐」税，换生产力与零运维。
13

套餐权益：商业内部也有「小商业 / 大商业」

即使不谈开源，官方商业内部也按套餐切能力——这决定「你订的商业版」具体含金量。

权益个人免费进阶高阶+旗舰/尊享/企业开源
创建云端 Agent➖➖✔️✔️无
本地 Agent 数量1（限时）1310 / 不限无 bridge
邀请项目人类成员受限受限高阶起✔️无
云手机/云电脑兑换➖➖✔️可扩容无
视频去水印 / 剪映导出基础弱起支持去水印更快通道企业通道无
选型提示 「用官方」不等于自动拥有云端 Claude Code / 云电脑——先对套餐表。开源则完全不存在这套梯子，但也没有平台额度。
14

场景剧本：该上哪条产品线

剧本 A · 企业内网客服 / 知识库问答，数据不能出网

首选开源 Studio：Knowledge + Plugin + SingleAgent + OpenAPI。 自管 MySQL/Milvus，接内网模型。不要指望飞书一键渠道——SDK 嵌入自有 Portal。

剧本 B · 运营团队要投研/自媒体/法务多角色一起干活

首选商业协作台：行业模板 Agent + 项目 @ 分工 + 长期记忆。 开源要自己养多个 Bot，且无项目协作与模板生态。

剧本 C · 产品经理要一个可安装 App / 小程序上线

首选扣子编程。开源只有 Agent/工作流应用壳，没有云端编程沙箱与一键 APK。

剧本 D · 漫剧 / 短视频内容生产

只能商业视频项目（Seedance）。开源零能力。

剧本 E · 工程师要弄懂 Agent 平台怎么造

开源 + 本站 80 天教程。商业闭源教不会你 Pipe/Compose/Crossdomain。

剧本 F · 已经在用本机 Claude Code，希望手机远程指挥

商业本地 Agent + coze-bridge。开源没有桥接层。

选型决策树

选开源，若…数据主权刚需；要改 Domain；要学引擎；能运维中间件；发布走 SDK/API。
选协作台，若…要多人多 Agent 项目；要行业模板；要记忆越用越懂；要桌面/移动；可接受套餐。
选扣子编程，若…要网页/App/小程序快速上线；要云沙箱；不想管 DevOps。
组合官方验证形态 → 开源私有化核心链路；或开源学原理 + 官方当生产力。不冲突。
