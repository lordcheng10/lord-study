开篇 · 这是个什么项目

AutoGPT 曾是引爆"自主 AI 智能体"热潮的鼻祖项目（2023 年 GitHub 一夜爆红）。如今它已转型为 AutoGPT Platform——一个低代码可视化平台，让你像搭积木一样，把一个个 Block（功能块）连成图（Graph），构建出能持续运行的 AI 智能体。

🎯 一句话：在 AutoGPT Platform 里，一个 AI 智能体 = 一张由 Block 连成的图。每个 Block 是一个有"输入口/输出口"的功能积木（调 LLM、发邮件、读网页…），你把它们的口用线连起来（前一个的输出→后一个的输入），就搭出了一个自动化流程。平台负责执行这张图、计费、管凭证。

🧱

Block 积木

300+ 现成功能块，带类型化的输入/输出口和 run() 逻辑。

🕸️

Graph 图

把 Block 连成图 = 一个智能体。前块输出流向后块输入。

⚙️

执行引擎

后端拓扑执行图、管理数据流、并发、定时、实时推送。

💳

计费平台

SaaS 化：积分计费、凭证托管、市场（marketplace）。

关于两个部分（重要）：本仓库有两块——autogpt_platform/（现代平台：后端 + 前端可视化构建器，本教程主战场）和 classic/（经典 AutoGPT + Forge，即那个引爆热潮的"自主循环智能体"，现为历史遗产）。我们主讲现代平台的源码，并用一天（Day 19）讲经典 AutoGPT 的起源故事。

AutoGPT Platform 的核心心智模型：Block 连成 Graph——

Block A读网页
输出：文本→连线→ Block B调 LLM 总结
输入：文本 输出：摘要→连线→ Block C发邮件
输入：摘要= 一个智能体"网页摘要邮件"
为什么用"积木搭图"？ 让不会写代码的人也能构建 AI 自动化——拖拽连线即可。同时对开发者，Block 是可复用、可组合、可计费的标准单元。这和 n8n、Zapier 的"节点连线"理念一脉相承，但每个节点可以是 AI 能力。
