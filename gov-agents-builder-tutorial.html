00

开篇 · 你要交付什么

这份教程和 框架源码 21 天 不同：不教你读 toolkit 源码，而是教业务团队怎么把自己的场景做成一个可上线、有 KPI 的 Agent。

🎯 你交付的 = LangGraph 业务图 + Prompt + 下游 client + 评测样本 + 效果指标。 Critic 防幻觉、成本熔断、invoke envelope、case 持久化——平台 ai-trust-toolkit 包好，你不重复造。

三种交付形态（可叠加）：CLI（本机跑 · 数据不出门）· MCP（Cursor/Claude Code 一键调）· Pod（HTTP 被系统/定时任务调用）。活范例：bmc-agent（独立仓 CLI+MCP）· biz-link-gov-agent（Monorepo Pod）。

和源码教程的关系：想深入理解 Critic/Failsafe/Memory 怎么实现 → 去 源码 21 天。想本周就交付一个业务 Agent → 跟本教程 5 天走。

02

两条接入路径 · 先选对

路径 A · 独立仓（推荐大多数业务方）

  • 不需要 gov-agents-platform 仓权限
  • 模板直链 / Portal 下载 zip 起仓
  • Nexus 拉 ai-trust-toolkit-bom[core]
  • 自己 git 仓迭代 · 发 Nexus · obelisk 部署
  • 范例：bmc-agent
Day 02 独立仓接入 →

路径 B · 平台 Monorepo

  • 需要平台仓 MR 权限
  • agentctl new / agent-creator / cp 老 agent
  • 全仓 3 处必改：workspace + AGENT_REGISTRY + AGENT_META
  • build_v1_router 挂标准 API
  • 范例：sre-rca-agent · biz-link-gov-agent
Day 03 Monorepo 接入 →
怎么选？没仓权限 → 路径 A。有权限且 agent 要进平台 CI/共用 → 路径 B。不确定 → Day 01 决策树 4 问。
