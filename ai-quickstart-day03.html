学会指挥 AI（Prompt 入门）

昨天你让 AI 第一次开口回话了，但可能发现它答得不一定合你意。今天教你怎么"指挥"它——同样一个问题，会不会说话，AI 给你的答案能差出十万八千里。这就是传说中的"提示词（Prompt）"。

1234567 你在第 3 天
①

为什么它答得飘忽不定

你有没有发现：同一个问题问 AI 两次，答案可能不太一样；问得含糊，它就答得又空又长。这不是 bug，是它的工作原理决定的。

🎤 AI 像个"接话高手" 大模型的本质，就是顺着你给它的话往下接。你开的头是啥样，它就顺着接成啥样。你说"写点东西"，它只能瞎猜你要啥；你说"写一条 50 字、活泼语气的奶茶店朋友圈"，它立刻知道该往哪接。你把话说清楚，它就接得准。

👶 那是不是我问得越啰嗦越好？

🧑‍🏫 不是啰嗦，是说清楚。关键是把三件事讲明白：我要它扮演谁、我要它干什么、我要它用什么格式给我。下面这三招就是教你把这三件事说明白。

②

三招把 AI 指挥好

记住这三招，你就超过 90% 只会说"帮我写个东西"的人了：

第一招 · 把话说清楚（具体 + 要格式）
别说"介绍一下杭州"，要说"用 3 个要点介绍杭州，每点不超过 20 字，面向第一次来玩的游客"。
👉 越具体、越指定输出格式，答案越好用。
第二招 · 给个例子（few-shot）
想让它按你的样子来，就先给它看一两个例子。比如你想把商品名变成广告语，就先给它 1 个"商品名 → 广告语"的示范，它立刻就懂你要的调调。
👉 与其解释半天，不如甩一个例子。
第三招 · 给它一个角色（system 消息）
在对话最前面，先给它设定一个身份："你是一个耐心的小学数学老师"。它后面所有回答都会自动带上这个身份的语气和专业度。
👉 这一句叫 system 消息，是"给 AI 定人设"的官方开关。
💡 一句话记住三招 说清楚（要什么）+ 给例子（像什么）+ 给角色（是谁）。 这就是提示词的全部核心，剩下的都是熟能生巧。
③

动手：加一句"角色 + 格式"，对比效果

还记得昨天的 messages 吗？昨天里面只有一条 user（你说的话）。今天我们在它前面加一条 system（给 AI 定人设），再在问题里指定输出格式。先看没优化的版本：

from openai import OpenAI
client = OpenAI(api_key="你的钥匙", base_url="https://api.deepseek.com")

# 加之前：只丢一句含糊的话，它会答得又空又长
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "介绍一下 Python"}],  # user = 用户说的话
)
print(resp.choices[0].message.content)

现在加上"角色"和"格式要求"，感受一下差别：

from openai import OpenAI
client = OpenAI(api_key="你的钥匙", base_url="https://api.deepseek.com")

resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[
        # system = 给 AI 定人设，放在最前面
        {"role": "system", "content": "你是一个只说人话的编程启蒙老师，不用术语"},
        # user = 具体要求 + 指定输出格式
        {"role": "user", "content": "用 3 个要点介绍 Python，每点不超过 20 字"},
    ],
)
print(resp.choices[0].message.content)
🎉 见证差别
两段分别跑一次，对比一下：加了 system + 格式要求后，答案是不是更短、更像人话、更好用了？你没换模型、没多花钱，只是"话说得更明白"，效果就天差地别——这就是提示词的威力。

👶 system 和 user 到底啥区别？我老记混。

🧑‍🏫 简单记：system = 设定它"是谁、该怎么表现"（幕后导演给的角色设定），user = 你当场问的话。system 通常只写一条放开头，user 是你每次实际提的问题。

④

小结 & 提示词口诀

把今天的三招浓缩成一张随手可查的小抄：

招式怎么用例子
说清楚具体 + 指定输出格式"列 3 条，每条 ≤20 字"
给例子甩 1~2 个示范"苹果→每天一颗，医生远离你"
给角色system 里定人设"你是资深 HR"
🌟 小技巧写不好提示词时，可以直接让 AI 帮你写提示词："帮我写一段提示词，用来让 AI 把中文翻成地道英文"。让 AI 帮你指挥 AI，真香。
🎯 今天你收获了什么
✅ 明白了 AI"顺着你的话往下接"，所以话怎么说，答案就怎么样；
✅ 掌握了三招：说清楚、给例子、给角色；
✅ 亲手在 messages 里加了 system 消息和格式要求，看到了"加之前 vs 加之后"的差别——你会写提示词了！

现在你会指挥 AI 了，但它有个大毛病：转头就忘，记不住你上一句说了啥。明天我们治好它的"金鱼记忆"，做一个能连续聊天的机器人 🐟
