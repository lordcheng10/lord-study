P02 · 智能体编排与调试对话

本课从零创建一个「竞品分析」智能体：点哪里、填什么、右侧预览怎么测——每一步都写清楚。前置必做 P00 环境 · 登录 · 模型；完成后进入 P04 知识库 RAG（第 3 课）。

🎯 第2课目标从零创建一个「竞品分析」智能体：写好人设与开场白，并在右侧预览与调试里拿到符合角色的回复。这是后续挂知识库、挂技能的统一入口。
0

前置检查（开始前逐项打勾）

本步目的 / 作用：P00 没配好模型的话，本课右侧预览会一直转圈或 Tokens=0，你会误以为是「智能体坏了」。
  • □ 浏览器能打开 http://localhost:8888（本地 Coze 已启动）
  • □ 已用邮箱登录，不是停在登录/注册页
  • □ 管理后台 /admin/#model-management 里至少 1 个模型状态为绿色启用（实录示例：claude-v1）
  • □ 左侧工作空间导航能看到「项目开发」和「资源库」两项
✅ 四项都勾上再继续。任意一项不满足 → 回到 P00 补做。
1

进入「项目开发」页

本步目的 / 作用：智能体卡片列表在这里；右上角「创建」是新建入口。
  1. 1.1 打开 Chrome / Edge，地址栏输入 http://localhost:8888 后按 Enter
  2. 1.2 若未登录：输入邮箱 + 密码 → 点「登录」（第一次先点「注册」）
  3. 1.3 登录成功后，看页面最左侧竖条导航（工作空间导航）
  4. 1.4 用鼠标单击第二项「项目开发」（图标像方块/应用，文字就是「项目开发」四个字）
  5. 1.5 地址栏应变为类似 http://localhost:8888/space/7662408410528219136/develop（中间数字是你的 space id，不必与示例相同）
  6. 1.6 页面主区域标题附近应出现「项目开发」；右上角有紫色/蓝色「+ 创建」按钮

图 1-1：项目开发页。左侧导航高亮「项目开发」；右侧是智能体/应用卡片；右上角是「+ 创建」。

红框标注 = 本步要点击 / 填写 / 观察的位置

✅ 验收：能看到「+ 创建」按钮；左侧「项目开发」处于选中/高亮状态。
点错入口若你点在「资源库」，页面标题会变成「资源库」且没有「创建智能体」流程 — 请回到侧栏再点「项目开发」。
2

创建智能体（不要创建应用）

本步目的 / 作用：得到一个可编排的 Bot；进入后 URL 形如 /space/:id/bot/:bot_id。
  1. 2.1 仍在「项目开发」页，鼠标移到页面右上角，找到「+ 创建」按钮（带加号）
  2. 2.2 单击「+ 创建」→ 屏幕中央弹出「创建」对话框
  3. 2.3 弹窗里通常有左右两块卡片：左边「创建智能体」，右边「创建应用」
  4. 2.4 用鼠标单击左边整块「创建智能体」区域（让它出现选中边框/高亮）— 不要点右边「创建应用」
  5. 2.5 点弹窗右下角或下方的「创建」按钮（在选中「创建智能体」之后才会进入下一步）

3

选择已启用的模型

本步目的 / 作用：决定右侧预览调用哪家大模型；必须选 P00 里「启用」的那条。
  1. 3.1 看页面中间栏最上方（三栏的中间那一列顶部）
  2. 3.2 找到「模型」或带模型名称的下拉框（可能显示默认模型名或「请选择」）
  3. 3.3 单击该下拉框 → 展开模型列表
  4. 3.4 在列表里单击你在 P00 启用的显示名称（示例：claude-v1）
  5. 3.5 下拉框收起后，应显示刚选的模型名
若下拉列表为空或没有你的模型：回 P00 管理后台确认该模型状态为「启用」而非「禁用」，保存后刷新本页（F5）。
✅ 验收：中间栏顶部模型下拉显示为你启用的名称（如 claude-v1）。
4

粘贴「人设与回复逻辑」

本步目的 / 作用：定义角色为 BitMart 的竞品情报分析师，监控 Binance / Bybit / Bitget / Gate.io；右侧预览将按此风格回复。
  1. 4.1 看页面最左栏，标题通常是「人设与回复逻辑」（或「Persona」）
  2. 4.2 用鼠标单击左侧大文本编辑区内部（光标闪动）
  3. 4.3 全选已有内容：Mac 按 ⌘+A，Windows 按 Ctrl+A
  4. 4.4 按 Delete 或 Backspace 清空
  5. 4.5 把下面灰色框全文复制（从 # 角色 到最后一行）→ 粘贴到编辑区（⌘+V / Ctrl+V）
  6. 4.6 粘贴后不用点保存 — 顶部会出现「草稿自动保存于 …」提示

红框标注 = 本步要点击 / 填写 / 观察的位置

图 4-2：实录 — 人设区已展开。

# 角色
你是一名专注加密货币交易所增长与运营的【竞品情报分析师】，服务对象是 BitMart 增长/运营团队。

# 目标
每日监控并分析：Binance、Bybit、Bitget、Gate.io 的活动、奖励政策与增长策略，产出可决策的结构化简报。

# 监控范围
1. 营销活动：Launchpool/Launchpad、交易赛、空投、打新、任务、邀请返佣
2. 奖励政策：费率折扣、VIP、新人礼、跟单分润、理财收益
3. 增长策略：获客、留存、锁仓、KOL/社媒、产品卖点
4. 风险信号：活动口径变化、地区限制、异常补贴

# 工作步骤
1. 信息采集（能用插件则用插件；否则基于公开认知并标注推断）
2. 结构化整理（按交易所输出统一字段）
3. 洞察与建议（策略解读 / 与我方差异 / 应对建议 / P0·P1·P2）

# 输出格式（默认日报）
1. 竞品日报 | YYYY-MM-DD
2. 今日要点（3–5 条）
3. 分平台动态
4. 横向对比
5. 对我方建议（P0/P1/P2）
6. 待核实事项

# 约束
- 客观、简洁、可执行
- 区分「已核实」与「合理推断」
- 无可靠来源不编造奖池数字
- 要求飞书报告时输出可直接粘贴的 Markdown
✅ 验收：左栏能看到完整人设；页面顶部有「草稿自动保存」类提示。
粘贴到错的位置人设必须贴在左栏「人设与回复逻辑」，不要贴在右侧预览输入框或中间栏开场白里。
5

配置开场白与预置问题

本步目的 / 作用：用户打开预览时先看欢迎语，并可一键点预置问题，不用自己想第一句。
  1. 5.1 看中间栏，向下滚动找到「对话体验」区块
  2. 5.2 展开「开场白」（有的版本叫 Opening / 欢迎语）
  3. 5.3 单击开场白文本框 → 清空 → 粘贴下面第一段 copybox 全文
  4. 5.4 在同一区块附近找到「预置问题」或「Suggested questions」
  5. 5.5 逐条添加 3 个预置问题（点「+ 添加」后粘贴，或一行一条）：
你好，我是竞品情报分析师。可监控 Binance / Bybit / Bitget / Gate.io 的活动、奖励政策与增长策略，并输出可直接发飞书的日报。
生成今日四所交易所竞品日报（适合飞书粘贴）
对比 Binance 与 Bybit 近一周获客奖励力度
提取 Bitget / Gate 新人礼与邀请返佣差异
  1. 5.6 若看到「用户问题建议」开关 → 拨到开（可选，推荐开）
✅ 验收：右侧预览区顶部应显示开场白文案；下方出现 3 条可点的预置问题 chip。
6

右侧「预览与调试」发测试消息

本步目的 / 作用：不发布也能验证模型 + 人设是否生效；本课最重要的动手验收。
  1. 6.1 看页面最右栏，标题为「预览与调试」
  2. 6.2 再次确认中间栏顶部模型为你启用的那条（步骤 3）
  3. 6.3 在右栏底部输入框单击（占位符可能是「输入消息…」）
  4. 6.4 粘贴测试句（复制下面 copybox 全文）：
先不要调用插件。用三句话介绍你自己的职责。
  1. 6.5 按 Enter 发送（或点输入框右侧发送箭头按钮）
  2. 6.6 等待 10–30 秒（首次调用模型可能较慢，右栏会出现 loading / 打字动画）
  3. 6.7 阅读回复：应提到「竞品」「Binance / Bybit / Bitget / Gate.io」「BitMart」等关键词
