本系列最重要的一课：在应用「竞品日报实战」里编排工作流 daily_competitor_report， 用 LLM 生成四所交易所竞品日报 → Python Code 安全编码 JSON → HTTP 推送到飞书（或 httpbin 演示）。 前置：已完成 P07 应用 IDE（应用和工作流空壳已建好）。

🎯 第6课目标（核心）在应用内把工作流 daily_competitor_report 编成 开始 → LLM → Code(json.dumps) → HTTP(RAW_TEXT) → 结束，试运行成功（演示可用 httpbin），并理解飞书 400/19001 为何必须用 Code 转义。

6

添加「代码」节点（Python）— 编码飞书 JSON

为什么必须有 Code 节点？
飞书自定义机器人要求 POST Body 是合法 JSON：{"msg_type":"text","content":{"text":"..."}}。
日报含换行、双引号。若在 HTTP 用 JSON 模板直接塞 LLM 长文本，不会自动转义，飞书返回 400 / errcode 19001。
正确做法：Python json.dumps() → HTTP 用 RAW_TEXT 原样发送。

6.1 放入画布

  1. + 添加节点 → 代码 → 语言选 Python 3（开源版仅 Python）
  2. 节点名称改为 编码飞书消息
  3. 描述可写：把日报安全编码成飞书 webhook JSON
  4. 重新连线：开始 → 生成竞品日报 → 编码飞书消息 →（暂）结束

6.2 输入 / 输出映射（最容易配错）

方向本节点变量名引用上游类型
输入report生成竞品日报.outputString
输入hint开始.lark_hintString
输出payload（本节点产出）String

6.3 代码全文（覆盖默认模板）

import json

async def main(args: Args) -> Output:
    params = args.params
    report = params.get('report') or ''
    hint = params.get('hint') or ''
    # 飞书文本前缀：含「竞品日报」可过关键词安全设置
    text = '【竞品日报】' + str(hint) + '\n\n' + str(report)
    # 飞书单条文本建议不超过约 4000 字，保守截断
    if len(text) > 3500:
        text = text[:3500] + '\n...(内容过长已截断)'
    payload = json.dumps({
        'msg_type': 'text',
        'content': {'text': text}
    }, ensure_ascii=False)
    ret: Output = {'payload': payload}
    return ret

图 8：代码节点配置示意 — ① 输入映射 report/hint → ② 输出 payload → ③ Python 编辑区。

代码做了什么对应飞书要求
json.dumps(..., ensure_ascii=False)中文保留，且自动转义引号换行
前缀 【竞品日报】机器人若开「自定义关键词」必须含该词
截断 3500 字避免超长被飞书拒绝
输出 payload给 HTTP 节点当 RAW_TEXT 整体发送
跳过 Code 直接 HTTP 拼 JSON httpbin 可能仍返回 200，换真飞书几乎必现 400 / 19001。这是本课最关键的工程经验。
✅ 验收：输入两个映射正确、输出有 payload、代码含 json.dumps 与 【竞品日报】。

关于「每日自动」— 无内置 Cron

本步目的 / 作用：事实：开源 Coze Studio 工作流编辑器没有内置定时触发节点（代码注释里写 will support soon）。所以「竞品日报」的「每日」要靠外部调度。
  1. 本课目标：手动试运行跑通 — 已完成
  2. 若要每天 9:00 自动推：需先 发布应用，再用 crontab 调 OpenAPI
  3. 具体 curl、PAT Token、workflow_id 获取 → 见 P08 发布 · PAT · OpenAPI
# P08 会详讲，这里仅预览（每天 9:00）
0 9 * * * curl -sS -X POST 'http://localhost:8888/v1/workflow/run' \
  -H 'Authorization: Bearer <你的PAT>' \
  -H 'Content-Type: application/json' \
  -d '{"workflow_id":"<工作流ID>","parameters":{"report_date":"'"$(date +%F)"'","lark_hint":"增长情报群"}}' \
  >> /tmp/coze-comp-daily.log 2>&1

工作流 ID：打开画布时 URL 末尾数字，如 .../workflow/7662919178956832768
