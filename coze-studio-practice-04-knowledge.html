P04 · 知识库 RAG 问答

创建文本知识库 → 上传本地 Markdown → 挂到智能体 → 用「库内暗号」提问验证命中。前置：已完成 P02。

1

打开资源库

作用：知识库、插件、工作流、数据库等都从「资源库」创建。
  1. 左侧工作空间导航点 资源库
  2. 地址类似 /space/<space_id>/library

图：资源库列表页。右上角紫色按钮是 + 资源。

2

创建文本知识库

  1. 点右上角 + 资源
  2. 下拉里选 知识库
  3. 在弹窗中：
    • 格式选 文本格式（默认高亮）
    • 名称：实战教程知识库
    • 描述：可写「竞品日报实战用示例」
    • 导入类型选 本地文档
  4. 点 创建并导入（不要只点「完成创建」，否则不会进入上传向导）

图：+ 资源 菜单，第四项是「知识库」。

图：创建知识库弹窗 — 文本格式 + 本地文档。

图：填好名称/描述后点「创建并导入」。

✅ 验收：跳转到上传页，顶部有四步进度：上传 → 创建设置 → 分段预览 → 数据处理。URL 含 /knowledge/<id>/upload。
3

准备并上传文档

作用：把私有文档切片 + 向量化，供检索。演示优先本地 MD/TXT。

先在本机新建文件 coze-kb-sample.md，粘贴：

# BitMart 竞品情报样例

## 产品要点
- BitMart 关注交易赛、邀请返佣、Launchpad 类活动。
- 对标交易所：Binance、Bybit、Bitget、Gate.io。
- 内部暗号：BM-INTEL-2026

## 使用说明
本文件仅用于 Coze 知识库实战验收：提问「内部暗号是什么」应能命中。
  1. 在上传区点击或拖拽该文件（支持 PDF / TXT / DOCX / MD；单文件 ≤100MB）
  2. 确认列表出现文件名后，点右下角 下一步
  3. 后续「创建设置 / 分段预览」可先用默认参数，一直点到「数据处理」完成
  4. 等待状态变为处理完成（可能需几十秒到数分钟）

图：已选中 coze-kb-sample.md，可点「下一步」。

常见卡点 点了「完成创建」而不是「创建并导入」：回到资源库重新创建，或进入该知识库再点上传。
处理一直转：检查 Docker 资源；ES/Milvus 容器是否健康。
飞书文档导入：开源需额外 OAuth，本课不要走这条。
4

挂到智能体

  1. 打开你在 P02 创建的智能体 IDE
  2. 中间栏找到 知识 → 文本，点 +
  3. 勾选 实战教程知识库 并确认
  4. 确保模型仍是已启用模型

图：中间栏「知识」下有文本 / 表格 / 照片入口。

5

验收提问

在右侧预览发送（务必用库里的专有词）：

根据知识库回答：内部暗号是什么？只回答暗号本身。
✅ 通过标准：回复中出现 BM-INTEL-2026（或明确引用该样例文档）。若模型编造其它暗号，检查知识是否挂载成功、文档是否处理完成。
未挂知识时，模型可能胡说。验收必须用「库内独有暗号」，不要问通用问题。
