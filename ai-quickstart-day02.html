跑通第一句对话

昨天我们搞懂了"大模型 = 会动嘴的实习生"。今天就动手，让这个实习生第一次开口回你话。全程照着做就行，看到它回你话的那一刻还挺爽的 🎉。

1234567 你在第 2 天
①

装 Python（3 分钟）

Python 是最适合新手的编程语言。装它就像装个普通软件一样简单：

做法：打开 python.org/downloads → 点大大的黄色下载按钮 → 双击安装。
Windows 用户注意：安装第一屏，一定勾选下方的 "Add Python to PATH" 再点安装（这一步很关键，漏了后面命令会找不到 python）。

装完验证一下：打开"终端"（Windows 叫 命令提示符 / PowerShell，Mac 叫 终端 Terminal），输入这一行回车：

python --version

只要能显示出一个版本号（像 Python 3.12.x），就成功了 ✅。（Mac 上如果没反应，试 python3 --version。）

👶 "终端 / 命令行"是啥？我有点怕那个黑框框。

🧑‍🏫 别怕，它就是一个"用打字代替点鼠标"给电脑下命令的地方。你今天只需要在里面打几行字、按回车，照抄就行，不会搞坏电脑。

②

拿一把"钥匙"（API Key）

🔑 API Key = 打给"超级实习生"的电话号码 + 门禁卡 大模型跑在别人家的服务器上，你要"打电话"叫它干活。API Key 就是那串专属你的钥匙：拿着它，你的程序才能连上大模型。用多少算多少钱（入门阶段几毛几块，很便宜；不少家还送新用户额度）。

任选一家注册、拿到一串 key 就行。下面几家写法都一样（后面代码通用）：

厂商特点拿 key 的地方
DeepSeek便宜、国内直连、新手友好platform.deepseek.com
通义千问（阿里）有免费额度、国内直连百炼 bailian.console.aliyun.com
OpenAI最经典，但国内访问不便platform.openai.com
⚠️ 钥匙要保管好拿到的 key 长得像 sk-xxxxxxxx。别发到网上、别提交到 GitHub——它关联你的账户余额。今天先复制下来放手边，下一步用。
③

装一个小工具包

我们用一个叫 openai 的工具包来"打电话"（别被名字骗了，它同时兼容 DeepSeek、通义等一大票厂商）。在终端里敲这一行：

pip install openai

看到最后一行是 Successfully installed ... 就装好了 ✅。（如果 pip 没反应，试 pip3 install openai。）

📦 pip 是什么 pip 是 Python 的"应用商店"。别人写好的现成工具包，一句 pip install 名字 就装进来直接用，不用自己造。以后你会经常用到它。
④

5 行代码，让 AI 开口

新建一个文件叫 hello_ai.py，把下面这段抄进去。只改一处：把 你的钥匙 换成你第②步拿到的 key。（下面用 DeepSeek 举例，用别家就按注释改两处。）

from openai import OpenAI

# 1）连上大模型：填你的钥匙。用别家就改 base_url 和下面的 model
client = OpenAI(api_key="你的钥匙", base_url="https://api.deepseek.com")

# 2）给它发一句话（role=user 表示"这是用户说的"）
resp = client.chat.completions.create(
    model="deepseek-chat",
    messages=[{"role": "user", "content": "用一句话介绍你自己"}],
)

# 3）把它的回答打印出来
print(resp.choices[0].message.content)

保存后，在终端里进到这个文件所在的文件夹，运行它：

python hello_ai.py
🎉 见证时刻
如果一切顺利，屏幕上会打印出 AI 给你的一句自我介绍——这是你第一次用代码"指挥"大模型干活！ 那个"会动嘴的超级实习生"，现在归你调遣了。截个图纪念一下 😃
🔍 这 5 行到底干了啥（一句话版） 连上它 → 发一句话给它 → 拿回它的回答 → 打印出来。 就这么简单。后面几天的所有东西，都是在这个"发消息、拿回答"的地基上加花样。
⑤

报错了别慌（新手小抄）

第一次跑报错太正常了，几乎人人都会遇到。对照这张小抄，八成能解决：

报错里出现的关键词大概率原因 & 怎么办
ModuleNotFoundError: openai没装包。回第③步跑 pip install openai。
401 / Unauthorized / auth钥匙填错或没生效。检查 key 有没有复制全、有没有多空格。
Insufficient Balance / 余额账户没钱/没免费额度了，去充一点点（几块钱够玩很久）。
Connection / timeout / 超时网络连不上该厂商。换一家（如国内直连的 DeepSeek/通义）或检查网络。
model ... not foundmodel 名字和厂商对不上。用 DeepSeek 就写 deepseek-chat，用通义写 qwen-plus 等。

👶 实在跑不通怎么办？会不会是我太笨？

🧑‍🏫 绝对不是 😄。环境和 key 是所有人入门时最容易卡的一关，卡住很正常。把报错最后几行复制下来，问 AI（比如直接问 ChatGPT/DeepSeek"这个报错怎么解决"）——这本身就是程序员天天在干的事。搞定它，你就跨过了最高的那道门槛。
