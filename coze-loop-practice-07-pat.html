步

操作步骤

1

打开账户设置

侧栏底部头像 → 账户设置（注意文案是「账户」不是「账号」）。

2

创建 PAT

左侧切到 API 授权，点 添加新令牌，填写名称与过期时间，创建后立刻复制明文（只显示一次）。

3

调用 OpenAPI

用 PAT 调 Loop OpenAPI（评测 / Trace 上报等）。注意：这是平台 API Token，不是 LLM 的 api_key。

4

登出

用户菜单 → 退出登录，回到 /auth/login。

PAT 泄露等同账号权限；教程演示 Token 用完请删除。
