这个 Agent 做什么

业务目标：每天自动抓取 AI 相关资讯标题，编排成适合团队群播报的「每日简报」。

CLI 输入日期→ fetch 节点
HN RSS→ broadcast 节点
LLM 编排→ 📢 每日播报正文

起仓 + 全局改名

作用：从平台直链下载标准模板，改成你的包名。模板已带好 builder.py / core.py / CLI 骨架，避免从零搭。

执行命令（Skill 步骤 1 · 名字换成 ai-daily-news）：

curl -fL http://gov-agents-ui.bmaicsaws-prod.com/portal/v1/agent-template/download.zip -o /tmp/tpl.zip
unzip /tmp/tpl.zip && mv standalone-agent-template ai-daily-news && cd ai-daily-news
mv your_agent ai_daily_news
grep -rl 'your[-_]agent' . | xargs sed -i '' 's/your-agent/ai-daily-news/g; s/your_agent/ai_daily_news/g'
git init && git add -A && git commit -m "init ai-daily-news"

写业务图（核心）

作用：把 demo 回声 bot 换成「抓资讯 → 出播报」两节点图。节点在 nodes/，串图在包根 builder.py（不在 nodes/ 下）。

4a · 改 state — 节点间传什么

ai_daily_news/state.py

class AgentState(TypedDict, total=False):
    input: str              # 可选日期，如 2026-07-13
    output: str             # 最终播报
    raw_items: list         # fetch 抓到的标题
    headlines_text: str     # 给 LLM 的标题列表

4b · 新建 fetch 节点 — 抓 HN RSS

ai_daily_news/nodes/fetch.py

def fetch_node(state: AgentState) -> AgentState:
    items = _fetch_rss("https://hnrss.org/newest?q=AI&count=8")
    if not items:
        items = FALLBACK_ITEMS   # 网络失败兜底，测试也能绿
    headlines_text = "\n".join(f"- {it['title']}" for it in items[:8])
    return {"raw_items": items, "headlines_text": headlines_text, ...}

4c · 新建 broadcast 节点 — LLM 编排播报

ai_daily_news/nodes/broadcast.py · prompts/__init__.py

def broadcast_node(state: AgentState) -> AgentState:
    resp = get_llm("sonnet").invoke([
        SystemMessage(content=BROADCAST_SYSTEM.format(date=date_hint)),
        HumanMessage(content=f"原始资讯:\n{state['headlines_text']}"),
    ])
    return {"output": resp.content}

4d · 串图

ai_daily_news/builder.py

g.add_node("fetch", fetch_node)
g.add_node("broadcast", broadcast_node)
g.set_entry_point("fetch")
g.add_edge("fetch", "broadcast")
g.add_edge("broadcast", END)
